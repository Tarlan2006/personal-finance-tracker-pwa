# BASE2_REPORT — основа проекта Қаржы

Дата: 2026-11-02. Статус: основа и домен денег реализованы и проверены в среде разработки; **физический iPhone и Safari не проверялись; боевой Cloudflare прошёл только публичные GET, импорт в бою не проверен.**

## Что сделано
- **Ядро:** аккаунты (PBKDF2, блокировка после 5 попыток), сессии (хеш токена, cookie HttpOnly/Secure/SameSite=Strict, отзыв устройств, отзыв при смене пароля), ключи API `write`/`read` (хеш, показ один раз, метка, `last_used`, лимиты), идемпотентные записи, мягкое удаление, версии для конфликтов, миграции (`migrations/`), админ-скрипт (`add`, `set-password`, `list`, `revoke`, `disable`, `enable`, скрытый ввод пароля, проверка точного origin для `--remote`).
- **Домен денег:** записи (расход/доход), категории (создать/переименовать/перекрасить/удалить, стартовый набор), получатели с привязкой категории отдельно для расходов и доходов, правила по тексту, импорт CSV (сумма со знаком / две колонки / колонка типа), отчёт по каждой строке импорта, откат импорта, отчёты за месяц (по категориям и по получателям, количество и сумма), экспорт CSV.
- **«Команды»:** `POST /api/shortcuts/add` (JSON, urlencoded, multipart), `GET /api/shortcuts/summary`, ответы русским текстом, коды ошибок, `Idempotency-Key`/`id`, лимит 60/мин. Рецепты — `SHORTCUTS.md`.
- **Клиент (PWA):** вход (выпадающий список), Лента (по дням, поиск, правка, удаление), Отчёты (кольцевая диаграмма, список категорий, получатели с выбором категории), Добавить, Ещё (импорт, категории/правила, экспорт, быстрые команды, синхронизация, тема, устройства, пароль), нижняя панель, тёмная OLED/светлая темы, safe-area, `viewport-fit=cover`, apple-touch-icon 180×180 без прозрачности, manifest, `prefers-reduced-motion`, поля ≥16 px.
- **Офлайн-очередь:** IndexedDB, идемпотентные id, видимая причина сбоя и время следующей попытки, backoff с jitter (5 с → 15 мин), приоритет `Retry-After`, без опроса по таймеру, шифрование (AES-GCM) при выходе.

## Исправление атомарности и лимитов D1 — подготовка к выпуску

Два блокирующих риска аудита закрыты. Операции, контрагенты и отчёт записываются одной транзакцией D1.batch; SQL-ошибка откатывает всё. Конкурирующие загрузки вычисляют статусы дублей внутри транзакции. При потере ответа после COMMIT сохраняются и операции, и отчёт; повтор файла не создаёт новые операции.

Действующий предел — **500 строк на импорт**, включая служебные строки и продолжения PDF. На 501-й строке — 413 до финансовых записей. Большие выписки делить по непересекающимся датам, не разрывая операции одного дня; день больше лимита пока не поддержан. Причины до 200 символов, preview до 140; JSON отчёта предварительно проверяется по пределу 1 000 000 байт с запасом, ниже размера строки D1. Защита проверена на Unicode и управляющих символах. Миграций не требуется.

Измерено для 500 строк: код импорта — 2 вызова D1, dryRun — 7; HTTP с авторизацией/ограничением частоты — 4 и 9. Бюджеты — 7 и 12. Отчёт сохраняет статус каждой строки и инвариант imported + duplicates + rejected = total.

Проверки: **54 Vitest**, **26 Playwright**, typecheck и build зелёные. Новый `npm.cmd run test:import-runtime` прошёл **24 проверки в локальном workerd с D1**, включая все 3 синтетических PDF, 500/501 строку, повтор, изоляцию, ошибку операции и отчёта, конкурентный импорт. В Vitest также проверены сбой финального SELECT и потеря ответа после COMMIT. Повторная независимая сверка личных исходников без записи операций: Kaspi депозит 16/16, Gold 9/9, Halyk 69/69 по дате, сумме и направлению; Freedom остаётся выключенным.

Это готовность к выпуску исправления в указанных пределах, **не проверка выполнения на боевом Cloudflare**. Деплой, push, боевые миграции и изменение боевых записей в этом задании не выполнялись. Физический iPhone/Safari, реальная CPU-квота и дневные квоты тарифа не измерены. Ограничения дедупликации без ID операции и поддержка только изученных PDF-макетов остаются в силе. Старые частичные импорты без отчёта автоматически не восстанавливаются.

Итоговый размер сборок: клиент **59,03 КБ gzip**, Worker **599,20 KiB gzip** (локальный --dry-run). Сканер секретов: 0 находок, 79 файлов.
