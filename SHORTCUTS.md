# «Команды» (Shortcuts) на iPhone

Приложение «Команды» может добавлять записи и читать сводку **без открытия приложения Қаржы**. Ниже рецепты, которые собираются руками. Готового `.shortcut`-файла в проекте нет: его нельзя корректно подписать из этой среды.

> Проверено только на уровне сервера (запросы `curl`/тесты). Сборка самих команд на реальном iPhone **не проверялась**: названия действий в iOS могут немного отличаться по версии.

## 0. Ключи

В приложении: **Ещё → Быстрые команды → Создать ключ.** Нужны два ключа:

| Тип | Что умеет | Где использовать |
|---|---|---|
| `Запись` (`qk_w_…`) | только добавлять записи | быстрый ввод, триггеры, Share Sheet |
| `Чтение` (`qk_r_…`) | только получать сводку | виджет, Siri |

Ключ показывается **один раз**. Сервер хранит только его хеш. Отзыв — кнопка «Отозвать». Ключ записи не читает ничего, кроме ответа «Записано…». Ключ чтения ничего не пишет. Ключ не открывает приложение и не даёт менять пароль. Лимит: 60 запросов в минуту на ключ, тело до 4 КБ.

Ключ лежит внутри самой Команды на телефоне. Если телефон потерян — отзовите ключ в приложении.

Ниже `https://ВАШ-ДОМЕН` — адрес вашего Worker (после деплоя).

## 1. Эндпоинты

### Добавить запись

`POST https://ВАШ-ДОМЕН/api/shortcuts/add`

Заголовок: `Authorization: Bearer <ключ записи>`. Тело — **JSON** (рекомендуется), либо `application/x-www-form-urlencoded`, либо режим «Форма» (multipart) в «Командах».

| Поле | Обязательно | Пример |
|---|---|---|
| `amount` | да | `1500`, `1 500,50` |
| `direction` | нет (по умолчанию расход) | `расход` / `доход` (`out` / `in`) |
| `counterparty` (или `merchant`) | нет | `Magnum` |
| `category` | нет | `Магазины` (точное имя вашей категории, тип должен подходить к направлению) |
| `note` | нет | `обед` |
| `date` | нет | `2026-11-02` или `02.11.2026` (по умолчанию — сейчас) |
| `id` | нет | любая строка 8–80 символов `A-Za-z0-9_.:-` |

**Повторы без дублей:** передайте заголовок `Idempotency-Key` (или поле `id`) — одинаковое значение второй раз вернёт «Уже записано (повтор)» и ничего не добавит. Без него каждый запрос считается новой записью. В Команде удобно взять значение из действия «Текущая дата» в формате ISO + «Случайное число», сохранить в переменную **до** запроса и использовать её же при повторе.

Если категория не указана, запись попадёт в категорию, привязанную к получателю (или по правилу), иначе будет «без категории».

Ответы — короткий русский текст для «Показать результат» / «Произнести текст»:

| Код | Текст |
|---|---|
| 200 | `Записано: расход 1 500 ₸ — Magnum` / `Уже записано (повтор): …` |
| 400 | `Ошибка: Некорректная сумма` и т.п. |
| 401 | `Ошибка: Неверный или отозванный ключ` |
| 403 | `Ошибка: Этот ключ только для чтения, нужен ключ записи` |
| 413 | `Ошибка: Слишком большое тело запроса` |
| 429 | `Ошибка: Слишком много запросов…` + заголовок `Retry-After` (секунды) |

### Сводка

`GET https://ВАШ-ДОМЕН/api/shortcuts/summary[?month=2026-11]`, заголовок `Authorization: Bearer <ключ чтения>`.
Пример ответа: `2026-11: расходы 13 899 ₸, доходы 700 000 ₸, баланс 686 101 ₸. Больше всего: Магазины 12 000 ₸. Без категории: 3.`

## 2. Рецепты

В каждом рецепте действие **«Получить содержимое URL»** настраивается так (в этой инструкции — «блок ЗАПРОС»):

1. URL: `https://ВАШ-ДОМЕН/api/shortcuts/add`
2. Нажмите «Показать больше» → **Метод: POST**
3. **Заголовки** → добавить: `Authorization` = `Bearer ` + ключ записи (слово Bearer, пробел, ключ)
4. **Тело запроса: JSON** → добавить поля: `amount` (тип Текст) = переменная с суммой, `counterparty` (Текст) = …, при необходимости `direction`, `category`, `note`
5. Ниже добавьте «Показать результат» (или «Произнести текст») с результатом запроса.

### Рецепт 1. Быстрый ввод («Спросить ввод»)

1. «Спросить ввод» — тип **Число**, вопрос «Сколько?» → результат в переменную `Сумма`.
2. «Спросить ввод» — тип **Текст**, вопрос «Кому / где?» → `Кому`.
3. «Выбрать из меню» с пунктами `Расход`, `Доход` (необязательно; без него — расход). В ветке «Доход» — «Текст» `доход` → переменная `Направление`; в ветке «Расход» — `расход`.
4. Блок ЗАПРОС: `amount` = `Сумма`, `counterparty` = `Кому`, `direction` = `Направление`.
5. «Показать результат».

### Рецепт 2. Кнопка действия (Action Button) и Пункт управления

1. Соберите Рецепт 1 и назовите команду, например, «Трата».
2. **Кнопка действия:** Настройки → Кнопка действия → «Команда» → выберите «Трата».
3. **Пункт управления:** Пункт управления → «+» → «Добавить элемент» → «Команды» → выберите «Трата» (iOS 18+). На iOS 17 — через экран Домой/виджет.

### Рецепт 3. Виджет «Команд» на экране «Домой» и экране блокировки

1. Для сводки создайте команду «Сводка»: действие «Получить содержимое URL» (`GET`, URL сводки, заголовок `Authorization: Bearer <ключ чтения>`) → «Показать результат».
2. Экран «Домой»: долгое нажатие → «+» → «Команды» → виджет → «Изменить виджет» → выберите «Сводка» или «Трата».
3. Экран блокировки: долгое нажатие на экране блокировки → «Настроить» → поле под часами → «Команды» → выберите команду.

### Рецепт 4. Автоматизации (триггеры)

«Команды» → вкладка **Автоматизация** → «+» → выберите триггер → «Запускать сразу» (отключите «Уведомлять о запуске», если нужно) → «Выполнить команду» → ваша команда. Часть триггеров не умеет спрашивать данные — для них собирайте отдельную команду без «Спросить ввод» (с фиксированными суммой и получателем).

| Триггер | Что поставить | Пример |
|---|---|---|
| Время суток | «Время суток» → 21:00, ежедневно | команда «Напомнить внести траты»: «Показать уведомление». Автоматическое списание на сумму **не делайте** |
| Прибытие/выход из места | «Прибытие» → место (например, «Работа») | команда «Обед» с `amount` = `2500`, `counterparty` = `Столовая`, `Idempotency-Key` = дата + `obed` — тогда за день запишется один раз |
| Подключение зарядки | «Зарядка» → «Подключено» | обычно используйте для напоминания, а не для записи |
| Открытие приложения | «Приложение» → «Открыто» → выбрать банковское приложение | команда запускает Рецепт 1: после оплаты внесите сумму |
| NFC-метка | «NFC» → просканировать метку, приклеенную, например, у кофемашины | команда с фиксированной суммой/получателем |
| Режим фокуса | «Фокусирование» → «Включается» | команда «Показать сводку» (Рецепт 3) |
| Транзакция Wallet | «Транзакция» → выбрать карту и категории | команда получает «Сумма» и «Продавец» как входные переменные: `amount` = `Сумма`, `counterparty` = `Продавец`. Работает только для карт в Apple Wallet. Kaspi/Halyk/Freedom в Wallet в Казахстане могут не поддерживаться — **не проверялось** |

### Рецепт 5. Меню «Поделиться» (Share Sheet)

1. Создайте команду → в настройках (значок «i») включите «Показывать в меню „Поделиться“» и тип входных данных «Текст».
2. Первым действием используйте «Вход команды» (Shortcut Input) → в переменную `Текст`.
3. Блок ЗАПРОС: `note` = `Текст`, `amount` = число, которое вы попросите «Спросить ввод» (Число), `counterparty` — «Спросить ввод» (Текст).
   Подходит, чтобы отправить банковское SMS/чек из «Сообщений» или «Почты» в заметку записи. Разбора текста СМС на сервере **нет** (это отдельное задание).

### Рецепт 6. Фраза для Siri

1. Назовите команду коротко: например, «Трата» или «Сводка расходов» (именно это название Siri распознаёт как фразу).
2. Скажите: «Привет, Siri, Трата». Siri запустит Рецепт 1 голосом; «Сводка» — Рецепт 3 и произнесёт результат, если добавить действие «Произнести текст» после запроса.

## 3. Проверка с компьютера (curl)

```
curl -X POST https://ВАШ-ДОМЕН/api/shortcuts/add \
  -H "Authorization: Bearer <КЛЮЧ-ЗАПИСИ>" -H "Idempotency-Key: test-0001" \
  -H "Content-Type: application/json" \
  -d '{"amount":"1500","counterparty":"Magnum","direction":"расход"}'

curl https://ВАШ-ДОМЕН/api/shortcuts/summary -H "Authorization: Bearer <КЛЮЧ-ЧТЕНИЯ>"
```
