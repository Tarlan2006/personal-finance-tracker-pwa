# AGENTS.md — инструкции для Codex

Проект: личный трекер финансов (PWA для iPhone). Cloudflare Worker + D1 (SQLite) + React/Vite/TypeScript. Язык интерфейса и общения с владельцем — русский; код и имена — английские.

## Команды (Windows: `npm.cmd` / `npx.cmd`)
- `npm run typecheck`, `npm test` (Vitest, реальный SQLite через `worker/dev/sqlite-d1.ts`), `npm run build`, `npm run test:e2e` (Playwright, эмуляция iPhone), `npm run scan-secrets`.
- Перед каждым коммитом: typecheck + test + build + scan-secrets зелёные. Для e2e при необходимости задайте `CHROMIUM_PATH`.

## Правила
1. Миграции только новыми файлами `migrations/000N_*.sql`; существующие не править.
2. Деньги — целые тиыны. Время — UTC мс; месяцы и дни по UTC+5.
3. Каждый маршрут `/api/*` фильтрует по `account_id`; на любой новый маршрут — тест на изоляцию аккаунтов в `worker/test/money.test.ts`.
4. Импорт выписок: каждая строка файла обязана получить статус `imported`/`duplicate`/`rejected` с причиной (инвариант `imported + duplicates + rejected = total`). Банковские парсеры писать только по реальным образцам, образцы с настоящими данными в репозиторий не класть (обезличить).
5. Без ИИ в классификации: только детерминированные правила и привязки пользователя.
6. Лимиты D1: считать обращения к хранилищу (`X-Storage-Ops`), бюджеты в `worker/test/ops.test.ts`; без опроса сервера по таймеру.
7. Секреты, пароли, ключи, реальные выписки не коммитить и не печатать. Живые данные не создавать без команды владельца.
8. `git push` — только по просьбе владельца, без `--force`. Деплой (`wrangler deploy`, миграции на боевую базу) — только по просьбе владельца.
9. Клиентский JS ≤ ~100 КБ gzip (сейчас ≈ 59). Новые зависимости — минимально.
10. Не приукрашивать: что не проверено (физический iPhone, боевой Cloudflare) — писать прямо в `docs/STATUS.ru.md`.
